# EagleEye プレイヤー比較：固定基準値の調査・暫定修正（2026-10-14）

## 結論

「選択したプレイヤーの中で最も高い値を100%」とするレーダーは、プレイヤーを追加・削除するだけで既存プレイヤーの形が変わるため、強さの絶対比較には不適切。固定の基準値が確認できるまで、レーダーの百分率換算を停止し、各ランキングの実スコアを同じ項目内で並べて表示する。

## 確認できた事実

1. MightPulse公開API仕様（https://api.mightpulse.com/）は `ranks.leaderboards[]` を `name / value / kingdom_rank` と説明するが、秘境の試練の各 `value` の数式、単位、上限値、カテゴリーごとの基準値は説明していない。
2. 公開プロフィールの表示例では、Coliseumが約10K、Forest of Lifeが約20K、Crystal Caveが約30K、Knowledge Nexusが約40K、Molten Fortが約50K、Radiant Spireが約60Kを起点とするように見えるデータがある（例：https://ks1566.com/player/234626307/、https://ks1566.com/player/233364669/）。これはカテゴリー識別用の固定オフセットを含む可能性を示唆するが、表示丸め・内部符号化・スコア仕様のいずれかを公開情報だけで確定できない。
3. MightPulseの公開プレイヤーページでは、同じエリアが「86-7」「39-9」などのステージ表記で表示される例も確認できた（https://www.mightpulse.com/player/4751274）。したがって、公開ページに見える値の表示形式だけで内部数値の意味を確定してはならない。
4. 攻略資料は6エリアが別々の育成要素を参照すると説明している。Coliseum＝英雄・英雄装備、Forest of Life＝ペット、Crystal Cave＝領主宝石、Knowledge Nexus＝学院・戦争学院研究、Molten Fort＝領主装備、Radiant Spire＝総合的な戦闘構成。出典：https://kingshotmastery.com/guides/mystic-trial
5. APIの `kingdom_rank` は順位であり、スコア値とは別フィールド。順位をスコアや割合へ変換しない。また、異なる王国の順位は直接比較しない。

## まだ確定していないこと

- 10,000 / 20,000 / 30,000 / 40,000 / 50,000 / 60,000 が本当に差し引くべきオフセットなのか。
- 各エリアの値が単純な数値スコアか、ステージ到達状況等を符号化した値か。
- 各エリアの固定上限値、ゲーム内の最大値、適切な比較基準値。
- MightPulseの実APIレスポンスとEagleEye保存Observationの値が公開プロフィールの表示値と同じ変換を経ているか。

このため、上記オフセットをコードで差し引いたり、推測の100%基準を設定するのは行わない。

## 暫定実装

- レーダーの「比較中の最強者＝100%」正規化を削除。
- 固定基準値・尺度が未検証であることを説明し、同じランキング内の実スコアを並べる表示に切り替える。
- ランキング間の数値は直接比較できないことを明示する。
- 回帰テストを更新し、最大選択値を100%とするコードが復活しないことを確認する。

## 固定基準値を確定するための次工程

1. APIキーをログやコミットに含めず、既存の管理者Probe/Raw Data経路から実レスポンスを1〜数名分確認する。
2. `leaderboards[].name/value/kingdom_rank` と公開プロフィールの表示形式を照合する。
3. 同一エリアでゲーム内表示・API値の関係を確認し、カテゴリーオフセットの有無と変換式を確定する。
4. 固定の上限値がゲーム仕様として存在するかを調べる。存在しない場合は、EagleEyeが観測した十分な標本から固定の基準値（例：事前に定義したパーセンタイル）を算出する設計を検討する。ただし、比較対象として選んだ人たち自身から基準値を算出しない。
5. 各エリアの基準値と変換式をテストで固定し、データ範囲外・未取得・異常値の挙動も検証する。

## コストと安全性

- 既存Observation・既存取得経路を優先し、比較画面のためだけの追加MightPulse呼び出しは増やさない。
- D1 Freeの読み取りを増やす広範囲な `ranking_snapshots` 取得は復活させない。
- 実値が確認できない項目を推測で補完しない。

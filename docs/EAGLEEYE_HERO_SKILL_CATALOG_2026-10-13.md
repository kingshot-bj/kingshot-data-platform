# EagleEye 日本語英雄スキル辞典 — 実装メモ

作成日: 2026-10-13  
対象: `kingshot-bj/kingshot-data-platform` / `main`

## 実装

- データ定義: `src/hero-skills-ja.js`
- 表示: `src/index.js` のプレイヤー比較ページ下部「日本語英雄スキル辞典（確認済み分）」
- 登録済み英雄: アルカ、アマデウス、エリック、ペーラ
- 登録項目: 討伐/遠征の区分、スキル名、確認できた初期値・最大値、説明、出典URL、確認日
- スマートフォン幅では辞典内テーブルを横スクロール可能にした
- D1のスキーマ・読み取り処理は変更していない

## 出典

- アルカ: https://altema.jp/kingshot/chara/25
- アマデウス: https://altema.jp/kingshot/chara/1
- エリック: https://altema.jp/kingshot/chara/17
- ペーラ: https://altema.jp/kingshot/chara/18

各ページの日本語表記と説明をベースにした外部調査データであり、ゲーム内画面そのものから全項目を照合したものではない。

## 重要な制約

1. MightPulse の `skill_levels[].id` と日本語のスキル名を結ぶ対応表はまだ確認できていない。そのため、辞典をプレイヤーのスキルLvに誤結合していない。
2. ペーラの討伐スキルの一部は、検索結果で初期値・最大値を完全に確定できないため「未確認」と表示する。
3. 現時点で全英雄を網羅したわけではない。新英雄・旧英雄を含む全件棚卸しと、出典間の表記差分チェックが残る。
4. GitHub main へのコミットは済んでいるが、この作業環境から Cloudflare Worker のデプロイ、本番HTTP確認、iPhone実機表示確認は行っていない。

## 次の実装課題

- 全英雄の日本語スキル名・説明・初期/最大値の収録を進める。
- MightPulse の実レスポンスでスキルIDの意味・順序を確認し、根拠が取れたIDだけ日本語名に対応付ける。
- ゲーム内表記と攻略サイト表記の不一致は、推測で統一せず「要確認」として記録する。

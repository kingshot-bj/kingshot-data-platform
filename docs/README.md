## Status terminology

- **Implemented:** 実コードで確認できる状態
- **Merged:** `main` に取り込まれた状態
- **Deployed:** Cloudflareへのデプロイ成功を別途確認した状態
- **Verified:** 対象のテストまたは実環境で確認した状態

これらは同じ意味ではありません。コミットやPRだけを根拠に本番反映済みと判断しないでください。
